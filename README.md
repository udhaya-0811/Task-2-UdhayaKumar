# Random Number Guessing Game 🎮

## 📌 Description
The Random Number Guessing Game is a Java console-based application.
The computer generates a random number between 1 and 100, and the
player tries to guess the correct number.

## ✨ Features
- Generates a random number between 1 and 100.
- Provides 3 rounds of gameplay.
- Allows 5 attempts per round.
- Gives hints when the guess is too high or too low.
- Validates user input.
- Displays the final score and game results.

## 🛠️ Technologies Used
- Java
- Random class
- Scanner class
- Loops
- Conditional Statements
- Exception Handling

## ▶️ How to Run

1. Install the Java Development Kit (JDK).
2. Download `NumberGame.java`.
3. Open a terminal in the folder containing the file.
4. Compile the program:

   javac NumberGame.java

5. Run the program:

   java NumberGame

## 🎯 Objective
To practise Java programming concepts such as random number
generation, loops, conditional statements, and exception handling.
